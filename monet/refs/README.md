# Style reference images (optional)

Put 1–3 public-domain Monet paintings in a folder named after a preset, e.g.

    monet/refs/water_lilies/water-lilies-1916.jpg
    monet/refs/london_fog/parliament-sunset.jpg

The Gemini backend sends them alongside your photo as style references (brushwork, palette,
texture only). This usually makes the result noticeably more "Monet" than the text prompt alone.
Good source: Wikimedia Commons (Monet died in 1926; his paintings are public domain).
Keep each image ≤ 1024 px on the long side — larger files only add latency.
